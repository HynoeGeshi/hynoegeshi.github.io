Editing FAQ

Know what to send.

Do I need to book a photo shoot too?

No. Editing Only is a standalone service for files you already have.

Can I send a reference look?

Yes. The editing request supports reference links so the color and finish can be discussed before work starts.

Why is there no fake before/after example?

A useful comparison has to show the same source image before and after editing. Until a verified pair is available, the site keeps that space honest instead of manufacturing proof.
